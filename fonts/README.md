# Fonts

The original game draws its interface with Windows system fonts ("Arial", "Times New Roman",
"Placard MT Condensed" and "Generals"). OpenGZH uses the system's own copies when they exist
(Windows has Arial and Times New Roman) and falls back to these freely licensed fonts, which work
on every platform:

| Original font          | Fallback here     | Notes                                    |
|------------------------|-------------------|------------------------------------------|
| Arial                  | Arimo             | metric-compatible with Arial             |
| Times New Roman        | Tinos             | metric-compatible with Times New Roman   |
| Placard MT Condensed   | Oswald            | condensed sans                            |
| Generals               | Oswald            | condensed sans                            |

All are under the SIL Open Font License (see the LICENSE files).
